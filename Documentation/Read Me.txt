2. FEATURE SUMMARY
--------------------------------------------------------------------------------
* Musical Engine:
  - 35 Scales (Diatonic, Pentatonic, Blues, Exotic, Arp Pools).
  - 40 Musical Styles (Acid, Rave, Techno, House, Electro, etc.).
  - 38 Response Strategies (Inversions, Echoes, Harmonic Cadences, etc.).
  - 24 Opening Motif types.

* Dynamic Scale Transposition:
  - Real-time automatic note conforming on Key, Scale, or Octave change.
  - Preserves minor/major 3rds, 6ths, 7ths, and functional intervals.
  - Reflects immediately in the Piano Roll, Step Grid, Preview Synth, and
    exported MIDI.

* Interactive 2D Piano Roll:
  - Click & drag notes vertically to transpose pitch with audio feedback.
  - Drag notes horizontally to move across steps.
  - Double-click to add or delete notes.
  - Drag note right edges to resize gate duration.
  - Left-hand keyboard for pitch preview.

* Step Grid Sequencer:
  - Independent 16-step Call and Response lanes.
  - Lane controls: Mute, Shift (< / >), Octave Transpose (-8ve / +8ve),
    Inversion (Inv), and Reversal (Rev).
  - Accent and Slide/Portamento toggles per step.

* 3-Way Split Views:
  - BOTH: Stacked Call and Response step grids above the combined Piano Roll.
  - CALL: Call Step Grid on top with Call Piano Roll below.
  - RESP: Response Step Grid on top with Response Piano Roll below.

* 303 Preview Synthesizer:
  - Built-in analog-modelled oscillator, 24dB resonant low-pass filter,
    and snappy decay envelope for instant standalone auditioning.

* Performance Knobs:
  - DENSITY: Dynamically thins or populates note events.
  - GATE: Adjusts global note duration (10% to 250%).
  - OCT JUMP: Introduces octave leaps (+-12, +24 semitones).
  - RESOLVE: Directs phrase-ending notes toward harmonic tonic resolution.

* Presets, History & Parameter Locks:
  - 8 memory slots (A-H) with Cmd+Click saving & Double-Click loading.
  - 24-step multi-level Undo/Redo history buffer.
  - Global MIDI Panic button (All-Notes-Off / All-Sound-Off).
  - Padlock vector icons next to Style, Strategy, Key/Scale, and Motif.

* Mutation Engine:
  - 9 surgical targets: Rhythm, Pitch, Articulation, Ending, Motif, Whole,
    Response, Call, or Linked.
  - 5 intensity levels: Tiny, Small, Medium, Strong, Brutal.

* MIDI Drag & Drop Export:
  - Direct drag to DAW timeline or desktop.
  - 4 Export Modes: Combined, Call Only, Response Only, Layered.
  - Whole-bar padding for seamless DAW looping.

* Universal Binary:
  - Native 64-bit performance on Apple Silicon (M1-M4) & Intel Macs.
  - Pre-codesigned and dequarantined.


3. INSTALLATION & SETUP
--------------------------------------------------------------------------------
macOS INSTALLATION:
Double-click "Call & Response MIDI v1.0.5 Installer.pkg" to install all
components automatically:
- VST3 Plugin:   /Library/Audio/Plug-Ins/VST3/Call & Response MIDI.vst3
- AU Component:  /Library/Audio/Plug-Ins/Components/Call & Response MIDI.component
- Documentation: /Library/Audio/Documentation/Viral Samples/Call & Response MIDI/

The installer automatically de-quarantines the files, applies code signatures,
sets POSIX permissions, and flushes AudioComponentRegistrar so your DAWs
(Logic Pro, Ableton Live, FL Studio, Studio One, Cubase, Reaper) recognize the
plugin immediately.

WINDOWS INSTALLATION:
Run "Call & Response MIDI v1.0.5 Windows Setup.exe" (built via Inno Setup,
build_windows.bat, or GitHub Actions CI):
- VST3 Plugin:   C:\Program Files\Common Files\VST3\Call & Response MIDI.vst3
- Standalone:    C:\Program Files\Viral Samples\Call & Response MIDI\
- Documentation: C:\Program Files\Viral Samples\Call & Response MIDI\Documentation\


4. QUICK KEYBOARD REFERENCE
--------------------------------------------------------------------------------
Action                              Gesture / Shortcut
--------------------------------------------------------------------------------
Save Preset to Slot A-H             Cmd+Click (or Shift/Alt/Ctrl) on slot button

Delete Note in Piano Roll           Double-Click (or Shift-Click) on existing note

Toggle Slide (Portamento)           Alt-Click note (cyan line)
