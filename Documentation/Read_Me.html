Installation & Setup

macOS

Run the included Call & Response MIDI v1.0.5 Installer.pkg to install:

  • /Library/Audio/Plug-Ins/VST3/Call & Response MIDI.vst3 (VST3)
  • /Library/Audio/Plug-Ins/Components/Call & Response MIDI.component (Audio Unit)
  • /Library/Audio/Documentation/Viral Samples/Call & Response MIDI/ (Documentation)

The installer automatically strips quarantine attributes (xattr -cr), verifies code signatures, sets permissions, and refreshes the macOS audio component cache.

Windows

Run Call & Response MIDI v1.0.5 Windows Setup.exe (built via Inno Setup script installer/windows/installer.iss, build_windows.bat, or GitHub Actions CI):

  • C:\Program Files\Common Files\VST3\Call & Response MIDI.vst3 (VST3 64-bit)
  • C:\Program Files\Viral Samples\Call & Response MIDI\Call & Response MIDI.exe (Standalone)
  • C:\Program Files\Viral Samples\Call & Response MIDI\Documentation\ (User Manuals & Read Me)
